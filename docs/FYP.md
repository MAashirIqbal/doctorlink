Final Year Project Proposal
1.1 Introduction
A full-stack Doctor Link System built using the MERN stack. It allows patients to easily find doctors by specialization, view details like experience and fees, and book appointments with secure online payments through Stripe. Doctors can manage their schedules, track earnings, and update their profiles using a dedicated doctor panel, while admins can oversee the entire system, adding doctors, managing users, and approving appointments. The platform ensures smooth interaction between patients, doctors, and admins with modern tools like React, Node.js, Express and MongoDB for efficient performance and data handling.

1.3. Project Overview statement:
A web-based Doctor Link System designed to make healthcare scheduling simple and efficient. Built with the MERN stack, it ensures secure online payments, smooth data management, and an easy-to-use interface for all users.

1.4. Project Goals & Objectives:
The main goal of “Doctor Link System” is to provide a simple and reliable online platform for booking and managing doctor appointments. It aims to connect patients, doctors, and admins in one system to make healthcare scheduling easier. The key objectives include enabling quick appointment booking, secure online payments, efficient doctor and admin management, protecting user data, and ensuring a smooth and user-friendly experience for all users.
1.5. High-level system components:

1.Patient Module: Allows patients to search doctors, book appointments, make payments, and manage their profiles.


2.Doctor Module: Enables doctors to view and manage appointments, track earnings, and update personal details.


3.Admin Module: Provides full control to manage users, doctors, and appointments through an admin dashboard.


4.Backend Server: Handles data processing, authentication, and communication between the frontend and database using Node.js and Express.js.


5.Database: Stores all user, doctor, and appointment information securely using MongoDB.


6.Payment Gateway: Manages secure online transactions through Stripe integration.


7.Cancellation & Refund Module: Allows patients to cancel appointments with automatic refunds for online payments.

8.Mobile & Web Application: A cross-platform system accessible via both web browsers and a dedicated mobile application for enhanced user reach.

9.Rating & Recommendation System: A module for patients to rate doctors and provide feedback, helping the system recommend the best rated specialists to users.

10.Web Scraping Module: An automated tool to gather and aggregate healthcare data and doctor information from external professional directories.
         
1.6. List of optional functional units:
1.	Doctor Rating and Review System: Allows patients to rate and review doctors after appointments.
2.	Search and Filter Enhancements: Advanced search by location, experience, or consultation fee.
3.	Chat or Messaging Feature: Enables direct communication between patients and doctors.
4.	Prescription Upload and Download: Lets doctors share and patients view medical prescriptions online.
5.	Report and Analytics Module: Provides admins with detailed reports on system usage and performance.
6.	Dark/Light Mode Option: Gives users the choice to switch between display themes for better comfort.
7.	Doctor-to-Doctor Referral System: If one doctor thinks another specialist is needed, they can refer the patient directly through the system.

1.7. Exclusions:
The system does not include emergency medical services or real-time video consultations. It also does not provide medical advice or diagnosis. Integration with external hospital systems, pharmacy services, or health insurance platforms is not part of this project. Additionally, offline appointment booking is excluded from the current scope.
1.8. Application Architecture:
The “Doctor link system” follows a three-tier architecture consisting of the frontend, backend, and database. The frontend is built with React to provide an interactive and user-friendly interface for patients, doctors, and admins. The backend is developed using Node.js and Express.js, which handle all server-side logic, APIs, authentication, and data flow between users and the database. The database, powered by MongoDB, securely stores user, doctor, and appointment information. Stripe is integrated for payments, while Cloudinary manages image storage. This architecture ensures smooth communication, scalability, and secure data handling across the entire system.

1.11. Tools and technologies used with reasoning:
Frontend
•	React: Fast, component-based UI framework that makes building interactive pages and reusable components easy.
•	Vite: Lightweight, super-fast build tool and dev server that speeds up development.
•	Tailwind CSS: Utility-first CSS for rapid, consistent styling without writing large custom stylesheets.
•	React Router: Simple routing for a single-page app so users can move between pages without full reloads.
•	Axios: Easy-to-use HTTP client for making API calls from the frontend.
•	React Toastify: Quick and user-friendly notifications for success/error messages.
Backend
•	Node.js — Efficient JavaScript runtime for building a scalable server using the same language as the frontend.
•	Express.js — Minimal, flexible web framework for creating REST APIs and handling routing and middleware.
•	Mongoose: Object modeling tool to interact with MongoDB using schemas and validation.
•	Bcrypt: Secure password hashing to protect user credentials.
Database & Storage
•	MongoDB: Flexible NoSQL database that fits well with JSON-like data and rapid schema changes.
•	MongoDB Atlas/Compass: Tools for managing and viewing the database during development and deployment.
•	Cloudinary: Cloud storage for images (profile photos, etc.) with built-in optimization and CDN delivery.
Payments & Files
•	Stripe: Trusted international payment gateway used for secure online transactions, with built-in webhook + refund support and a fully featured test mode that removes the need for a live merchant account during development.
•	Multer: Middleware for handling file uploads (e.g., doctor profile pictures) on the server.
Development & DevOps
•	VS Code: Popular code editor with extensions that speed up development.
•	Postman: API testing tool to test backend endpoints during development.
•	ES Lint: Linter to keep code consistent and catch common errors early.
Security & Reliability
•	HTTPS/SSL (deployment): To encrypt data in transit and secure user interactions.
•	Environment Variables (.env): Securely store API keys, DB URIs, and sensitive configuration outside source code.
Testing & Quality
•	Unit/Integration Testing (optional): Tools like Jest or Mocha can be used to test backend logic and frontend components to ensure reliability.

Flutter: To develop the cross-platform Mobile Application for iOS and Android (chosen over React Native for richer native performance and a single Dart codebase).

Puppeteer / Cheerio: Libraries used within the Node.js environment to perform Web Scraping for data collection.

Recommendation Engine Logic: Custom algorithms implemented in the backend to process user ratings and suggest top doctors.
