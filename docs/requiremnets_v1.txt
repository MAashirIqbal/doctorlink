1️⃣ Project Overview (High Level)

The Doctor Link System is a full-stack, role-based healthcare appointment platform that enables:

Patients to search doctors, book appointments, and make online payments

Doctors to manage schedules, appointments, and earnings

Admins to monitor, control, and manage the entire system

The system is developed using modern full-stack web technologies following Object-Oriented principles and three-tier architecture, suitable for a Final Year Project.

2️⃣ System Architecture Requirement
🔹 Architecture Style

Three-Tier Architecture

Presentation Layer (Frontend)

Application Layer (Backend APIs)

Data Layer (Database & Storage)

🔹 Communication

RESTful APIs over HTTP/HTTPS

JSON-based data exchange

JWT-based authentication

3️⃣ Frontend Requirements (Client Side)
